# 第 3 层第一步：普通纬平针周期单元求解器（Codex 任务书）

起草及 T0 修订：2026-11-21（Asia/Shanghai）。上位设计：[ALGORITHM_DESIGN.md](ALGORITHM_DESIGN.md) 第 4、4.1 节；总计划：[TECH_VALIDATION_PLAN.md](TECH_VALIDATION_PLAN.md)。**2026-11-22 用户已授权按文档基线 `4e68850414432898cafb5bb7d078eb52722955a8` 实施本任务 T1，完成后停止，不进入 T2–T8。**阶段句“当前关口是**三维算法重新设计**”保持不变，不修改或放宽现有 validator。下文验收口径保持 T0 修订定义，实际结果另记，不能把规范写成通过记录。

本轮保留离散弯曲能的整段长度系数、e(r) 与 Abel 核 ψ(r) 的数学关系、密度与 GSM 的单位换算。历史起草人的数值复核说明不作为本轮执行记录；本轮实际核验与 T0 的 validate/build 结果由交付报告单独记录。

## 0. 一句话目标

求解给定无摩擦杆与接触模型下的周期平衡构型，并与经验数据对照。

未来纯函数输入“全成圈单面布的拓扑 + 每针纱长 + 纱线参数”，输出模型下的横密、纵密、线圈中心线与包络厚度估计。不预先把这个平衡构型等同于真实干燥放松或充分放松状态；经验数据的实物状态须单独核对。

两类验收要分开看：

- **A 类（已覆盖的数学与数值检查）**：梯度、约束、平衡、不变性等检查通过，只支持已覆盖部分；多初值、分支和性能项按其各自口径报告，不等于证明代码没有错误。
- **B 类（经验量级与模型适用性检查）**：与状态、单位及来源明确的纬平针经验常数对照。失败时停止逐工况调参，检查材料参数、模型假设、数值误差、实测口径以及尚未覆盖的实现问题，再回到讨论。

“模型假设自洽”“数值实现通过检查”“实物验证通过”分别记录；A、B 都不能代替 T4 标定与 T5 未参与开发工况的验证。一组参数跑全部工况，不逐个工况调参。

## 1. 范围

T1 做：单纱系统（每路一条主纱，只弯曲、不可伸长）、可压缩接触模型（van Wyk + 压实距离 r_c 势垒）、周期单元（格矢量 3 自由度）、无外力平衡求解、指标输出、验证脚本、结果报告。

不做（留给第 2、3 步或更后）：氨纶、集圈、摩擦、扭转、标定界面、任何 UI / 渲染 / 预览接入、整布平铺。不改纱长求解器、二维仿真、`singleJerseyMachine`、`ProcessModel` 的行为。

## 2. 输入工况

所有影响物理结果的输入与派生量带六字段：**Value / Unit / Source / Measurement or derivation principle / Confidence / Applicable state**（按 AGENTS.md §5 与 PROCESS_VALIDATION.md）。Source 记录具体文献、测量或文件位置；估计值、推断值、假设值与实测分开。只有有实际文献来源的估计才标 `ESTIMATED_LITERATURE`；来源未核实的数值标 `ASSUMPTION` 或 `UNKNOWN`，不得冒充实测。

**数值参考纱线（尚非实物标定输入）**：20 tex 羊毛纱；纤维密度 1.31 g/cm³；纤维直径 21 µm；纤维模量 E_f = 3 GPa；van Wyk 参数 K = 0.01、φ0 = 0.5。当前这些数值来自讨论稿的测试设定；具体出处未落实前按 `ASSUMPTION` 记录，不能统称“Munden 实测材料”。K、φ0 是本接触模型的假设参数。模型内统一 mm、N，E_f 换算为 3000 N/mm²；K、φ0 无量纲，B 单位 N·mm²。由此推导（未来由参数模块计算，不手填结果）：

- 实体直径 d_s = √(4·tex / (π·ρ·1000)) mm（20 tex → ≈ 0.139 mm）；
- 有效直径 d_e = d_s / √φ0；
- 压实距离 r_c = φ0 · d_e（= √φ0 · d_s，单轴压扁到 φ = 1 时的中心距，见第 3 节接触）；
- 抗弯刚度 B = N_f · E_f · π d_f⁴ / 64（纤维可相对滑移的下限估计），N_f = tex / 纤维 tex。

**纱长工况（B 类对比用）**：每针线圈长度 l = 2.6 / 3.0 / 3.5 / 4.0 mm，对应本任务按 mm 定义的紧度指标 TF = √tex / l ≈ 1.72 / 1.49 / 1.28 / 1.12。这是预先指定的测试范围；引用文献紧度系数时先核对其长度单位，不能直接比较不同单位约定。

**参考工况（只报告，不验收）**：SOP-001 主纱单独织成普通纬平针，8.0 tex（`INFERRED`）、l = 2.3 mm、纤维按 N6/羊毛 60/40 估算，作为第 2、3 步的模型对照。2.3 mm 来自 2026-10-20 生产确认的拆纱放松实测 23 cm/100机针，来源及测量限制见 [YARN_LENGTH_CONTRACT.md](YARN_LENGTH_CONTRACT.md)；8.0 tex 的原料比反推链见上位设计第 7 节，原料比是否独立测得仍待确认。该反事实全成圈工况并无配套实物验证。

## 3. 模型（第一版固定写法）

- **主纱离散**：离散弹性杆，每针每路一个线圈 N_loop 个节点（候选生产设置 16–32，默认候选 24；验收参考计算允许 64、128 或更细，见 A14）。弯曲能 E_b = Σ B·|κb_i|² / ℓ̄_i，κb_i = 2(e_{i−1}×e_i)/(|e_{i−1}||e_i| + e_{i−1}·e_i)，ℓ̄_i = |e_{i−1}| + |e_i|（节点两侧**整段**长度之和，离散弹性杆写法）。若 ℓ̄_i 取两侧半段之和（Voronoi 长度），公式前须乘 1/2，才能对应连续值 (B/2)∫κ²ds 与 M2 的圆环解析值 2π²B/L。所有 e_i 使用第 4 节的周期实际边向量。
- **不可伸长**：T1 中节点为材料点，参考段长锁定。实现可用增广拉格朗日或强罚函数，但最终相对应变 ≤ 1e−4；每线圈纱长 = l（误差 ≤ 1e−4·l）。T3 的材料滑移与每针纱量边界不能靠删除这些局部约束实现，见第 8 节。
- **接触**（本节全部是**模型假设**，报告里原样列出）。分三层定义：
  1. *两根平行直纱的单位长度接触能 e(r)*：中心距 r < d_e 时按单轴压扁，接触宽度取 d_e，φ(r) = φ0·d_e / r，压力 p = K·E_f·(φ³ − φ0³)，单位长度法向力 f(r) = p·d_e。对 r 从 r 积分到 d_e：
     e(r) = K·E_f·φ0³·d_e·[ (d_e³/2)·(1/r² − 1/d_e²) − (d_e − r) ]，r ≥ d_e 时 e = 0。e 和 e′ 在 d_e 处都连续。
     压实点：该单轴压扁假设下 φ = 1 发生在 r = r_c = φ0·d_e，**不是** d_s（实体截面压扁成扁形后中心距可以小于圆形实体直径）。r_c 是本模型未排除非局部中心线段对的间隙界限，不自动证明局部扫掠管面或最终三角网格可行，也不构成多方向接触时的截面恢复律。
  2. *一般构型的总接触能*：用双重线积分核 E_c = ∬ ψ(|x(s) − y(t)|) ds dt，按第 4 节包含 yarnId、段身份、周期偏移的无序物理段对去重，每个每单元接触贡献只计一次。核 ψ 由 e 做 Abel 反演得到，使两根无限长平行直纱代入后还原 e(r)：
     ψ(ρ) = (K·E_f·φ0³·d_e / π)·[ d_e³·( √(d_e² − ρ²) / (2ρ²d_e²) + arccos(ρ/d_e) / (2ρ³) ) − arccosh(d_e/ρ) ]，ρ < d_e；ρ ≥ d_e 时 ψ = 0。
     该式需要在 M3 中独立数值核对 Abel 关系（∫ψ(√(r²+τ²))dτ = e(r)，相对误差 < 1e−6）。段对积分可用 q×q 点 Gauss–Legendre，但固定 q = 3 仅是测试起点，不能预设满足 0.1% 精度；可按接触支撑范围切分积分区域或自适应细分，分开记录节点密度、积分阶数和细分容差。只对最近距离 < d_e 的段对计算接触核，完整候选集与安全步长另按接触范围及扫掠包围体构造。
     同纱近邻排除按**具体周期像在展开材料坐标上的段区间最短弧长间隔** < 2·d_e 判断。沿纱连接及跨周期偏移决定这两个段是否属于同一条展开纱及其材料位置；不能对所有周期像套用取模后的最短弧长，不能仅因局部编号相同就排除。T1 不可伸长时材料邻域固定，但这不保证最近特征切换等数值运算处处光滑，梯度检查须覆盖这些边界。
  3. *势垒*（数值间隙保护，不属于已标定物理本构）：对每个未排除段对，取最近距离 r_ij，间隙 g = r_ij − r_c，激活宽度 ĝ = 0.1·(d_e − r_c)。0 < g < ĝ 时 E_bar = κ·w_ij·[ −(g − ĝ)²·ln(g/ĝ) ]，κ = K·E_f；g ≥ ĝ 时 E_bar = 0，g ≤ 0 不可行。现有候选权重 w_ij = (|e_i| + |e_j|)/2 必须检查同一曲线细分后的能量、梯度与格矢量反力是否收敛；逐段对最近距加和不自动具有细分一致性。若失败，先修订离散权重或改用有一致积分测度的保护方式，再固定规范与验收，不用重新调 K 掩盖离散问题。
     报告势垒能占比、激活段对数、势垒力及格矢量反力，以及权重/激活宽度敏感性。1% 能量占比只作诊断阈值；即使低于 1%，也不能断言势垒对反力或几何可忽略。
- **周期单元**：格矢量 a1 = (W, 0, 0)（沿横列、跨纵行）、a2 = (S, H, 0)（沿纵行、跨横列，S 为剪切），W、H、S 与节点一起优化，要求 W、H > 0、格矢量不退化。W、H 是整个 m 针 × n 路单元的尺寸；W/m、H/n 为**平均每针、每路节距**，实际线圈轮廓宽高另定义。周期连接与像范围见第 4 节；厚度方向 z 自由，消除刚体平移等规范自由度后计算残差。
- **自由尺寸平衡（含约束反力）**：令 x 为去除规范自由度后的节点坐标与 (W, H, S)，g(x) = 0 为段长约束，J = ∂g/∂x；周期实际边向量对格矢量的依赖必须进入 J。令 E = 弯曲 + 接触 + 势垒，λ* = argmin_λ ‖∇E + Jᵀλ‖₂，R = ∇E + Jᵀλ*。无外力自由平衡要求节点与 W、H、S 分量同时满足 A4。用增广拉格朗日、罚函数或投影法都按该定义事后检查；报告约束秩与乘子求解容差。
- **锁定 W、H 模式**：分开自由变量 q =（节点坐标，S）和固定变量 c =（W，H）。**只在自由方向求乘子**：λ* = argmin_λ ‖∇qE + Jqᵀλ‖₂；自由残差 Rq = ∇qE + Jqᵀλ*；尺寸反力 Fc = ∇cE + Jcᵀλ*，即 F_W、F_H。固定尺寸方向的非零反力不得放进待消除残差一起最小化。外力符号按 δ功 = Fc·δc 定义；在同一光滑平衡分支，Fc 应与约束最小能量 E*(c) 的尺寸导数一致，T4 优先按此核验。±5% 偏离的反力响应是分支诊断，非普遍单调定理。本步预留并正确返回反力，不做 UI。
- **初值与求解**：“放大约 1.3 倍”仅是几何构造参考；不能把目标材料长度同步改大。初值最终必须同时满足目标段长/总长、可行间隙、正确穿套关系，无法构造时返回不可行诊断，不直接进入优化。L-BFGS（或牛顿）+ 线搜索须采用连续碰撞检测（CCD）或有依据的保守步长界，确保**从旧构型到新构型的整个更新轨迹**保持未排除非局部段对 r > r_c；只检查接受步终点不够。周期像随 a1、a2 运动，扫掠候选和距离界必须包含这种运动，不能只检查旧构型的接触对。
- **三种几何检查分开**：T1 的非局部中心线间隙保护；T6 小周期单元的局部扫掠管面可行性（含局部弯曲、自包络与多方向接触）；T6 交付三角网格的实际表面相交检查（含周期接缝）。第一项不能自动证明后两项。第 3 层标量接触能本身不提供椭圆半轴与朝向；截面恢复接口按总计划 T6 明确定义，失败返回诊断，不在渲染层移动中心线。

### 3.1 T1 势垒离散修订记录（2026-11-22）

固定 3 mm 平行直纱的细分反例确认 `(li+lj)/2` 权重发散；改为 `li*lj/d_e` 乘段对最近距离势垒虽有有限极限，但在 N=6144 时相对连续参考仍有约 3.48% 能量、3.11% 法向导数偏差。按第 3 节已授权的数值离散修订，实际采用 `E_bar=(K*E_f/d_e)∬b(|x(s)-y(t)|-r_c) ds dt`，保留原 b、r_c 和激活宽度，并按支撑边界与物理长度切分积分。N=24/48/96/192、相位 0/¼/½、间隙为激活宽度 ¼/½/¾ 的固定几何能量与力误差分别小于 2.5×10⁻¹³、8.4×10⁻¹⁴。

这里改变的是数值保护的积分测度，不改变 e、ψ 或 K、φ0。积分势垒本身不被当作不可穿越证明；整段轨迹安全仍由移动周期像扫掠范围与距离 Lipschitz 保守界承担。旧候选反例和当前积分测度检查分开保存。势垒的形态影响仍按 A14 对实际求解分支检查，不能从上述固定几何结果直接推断可忽略。

## 4. 拓扑来源

不手写第二套机器逻辑（AGENTS.md §2、§3）。用 `resolveSingleJerseyOperations()` 跑一个全 K（全成圈）的 Cam Program，得到机器执行结果，再新写一个适配纯函数把它整理成“哪个线圈穿过哪个线圈”的图，供求解器使用。本步初始几何只需支持成圈线圈；遇到 T（集圈）或 M（浮线）直接报错 `UNSUPPORTED_IN_STEP1`，不做降级。

求解器内核只认这张图和周期尺寸（m 针 × n 路），不写死 1×1，以便第 3 步直接换成 4 × 8 的 SOP 循环。

每条纱、连接边和穿套关联至少保存：

- `yarnId`、材料段身份及沿纱有向顺序；不能用相同的局部节点编号判断是不是同一条展开纱。
- 跨界连接的整数偏移 `(p,q)`；实际边向量统一为 **e = x_to + p·a1 + q·a2 − x_from**。段长、弯曲、接触与格矢量导数共用这一定义。
- 穿套关联所指向的线圈/集圈身份及其具体周期像 `(p,q)`，同时记录有向穿套/局部正反关系。连接首尾与穿套跨界分别测试，不能仅保存“下一路的同编号线圈”。
- 可展开的材料坐标与累计绕行偏移，使同纱近邻排除按具体像的材料弧长判断；周期副本不重新分配物理材料身份。

无序接触键为 `((yarnId_i, segment_i), (yarnId_j, segment_j), p, q)`，与反向键 `(j,i,−p,−q)` 等价并只保留一次。零偏移同一段自身不计，但 **i = j 且 (p,q) ≠ (0,0)** 的接触不能由 `i < j` 规则整批排除；仍按展开纱的近邻规则判断。换基单元、重编号、复制单元后每线圈能量和梯度必须按 A5 一致。

像范围由当前单元、段的包围体与最大接触支撑范围求得；线搜索还须覆盖移动格矢量及节点轨迹的扫掠包围体。只有证明所有遗漏周期像在整个所检查轨迹上均超出作用/保护范围，才允许仅取 `(p,q) ∈ {−1,0,1}²`。小单元、剪切单元或长跨界段不满足该条件时按范围扩大枚举，并记录覆盖依据。

**M3 专项（区分公式与数值离散）：**

1. 用独立高精度积分核对 ∫ψ(√(r²+τ²))dτ = e(r)（相对误差 < 1e−6）及 e′(r) = −f(r)。至少覆盖 r/d_e = 0.55 / 0.65 / 0.75 / 0.85 / 0.95（φ0 = 0.5 时都在 r_c 与 d_e 之间）；临近 d_e 的近零能量额外报告绝对误差，不能除以零。
2. 两根周期平行直纱，周期 L = 3.0 mm、d_e ≈ 0.197173891 mm，N = 12 / 24 / 48 / 96 等分，对应段长 0.25 / 0.125 / 0.0625 / 0.03125 mm；分别测试相位差为段长的 0、1/4、1/2 以及上述五个间距。测量每单元积分除以 L 的单位长度接触能，使用足够周期像覆盖支撑范围。
3. 保留已独立核验的反例：**24 段、段长 0.125 mm、同相位、每段 3×3 Gauss–Legendre、r/d_e = 0.85 时，误差约 +0.8614%**，超过 0.1%。本轮轻量脚本已复现该值；完整记录见 T0 archives 的 formula-check.json。它否定“默认分段固定 q = 3 普遍满足精度”，并不否定 Abel 核公式。
4. 为每组固定杆几何单独收敛积分：提高 q、按支撑边界切分或自适应细分，直到单位长度接触能相对 e(r) 误差 < 1e−3，并核对能量导数/力随积分精度稳定。参考计算不得被生产默认上限截断。
5. 势垒单列固定几何的重复细分、相位改变、能量/梯度/反力检查；验证候选 w_ij 的细分一致性。与 Abel 接触能误差分别报告。实现验证还须覆盖段最近特征切换、周期换像与非局部候选的完整性。

M5 的强制数值检查未通过或分支报告不完整，不进入 M6；A8 等诊断不是要求所有初值/单元求得同一个解。分支差异若尚无法区分数值误差与模型多稳态，保留未决结论，不能宣布全部验收完成。

## 8. 后两步预告（本任务不做，只为接口留位）
