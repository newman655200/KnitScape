## 0. 一句话目标

把 R2 的 K 扫描从 K×{0.5, 1, 2} 延伸到 K×{1/4, 1/8, 1/16, 1/44}，**用实际求解**回答：抗弯刚度 B 被低估（等效为 K 被高估）最多能把横密斜率从 −0.39 拉到哪里，能否到约 −1。

**这是诊断，不是标定。** 任何结果都不得用来选择、调整或推荐 K、B 或其他参数的取值，也不改默认值。

## 1. 背景（只读）

- 实测（Hossain 2025，干放松）横密 ∝ l^-2.05；T1（K×1）∝ l^-0.39；经典充分放松态预期约 l^-1。
- 工作假设（`斜率差距来源设计比较`，架构师 2026-11-25）：差距分两段。**状态段** −2.05 → 约 −1，来自干放松态没有放松到底，由用户侧实物测量（D0）检验；**模型段** −1 → −0.39，候选解释之一是 B 被低估。本任务只检验模型段的这一候选。
- 代码里接触能和势垒能都 ∝ K·E_f（`yarnContact.js`），弯曲能 ∝ B（`fabricFormParams.js`）。总能量整体缩放不改变平衡构型，所以平衡态只依赖 K·E_f/B。**B×c 等价于 K/c**。当前 B 按纤维自由滑移取值（下界）；实心杆上界约为 N_f ≈ 44 倍，所以 K×1/44 对应 B 取上界。
- R2 QC：b_wale(K×0.5/1/2) = −0.534/−0.397/−0.274，db/dlnK ≈ 0.188。按此外推，K×1/44 时约 −1.1（仅外推）。本任务用实际求解替代这个外推。
- R2 QC 六点的 minDistanceOverDe 为 0.908~0.960，势垒能为 0，没有剪切分支。按趋势估计，K×1/44 时约 0.85，离势垒支撑区（≤ 0.55）还远，但仍需记录。

## 2. 研究问题与预先登记的判读阈值

阈值由架构师在运行前登记。**运行后不得修改阈值、增减工况或改变计算口径**，只能如实报告。落在“不确定”区间也是有效结论。

### R3a-Q：K×1/44（等效 B 取实心杆上界）时的横密斜率

斜率口径与 R2 QC 完全相同：三个 l 上对 ln 横密 vs ln l 作含截距、等权最小二乘，得到 b_wale(K)；同时报告 b_course(K) 和拟合残差。

| b_wale(K×1/44)（主判据） | 判读 |
|---|---|
| ≤ −0.9 | 抗弯刚度口径足以把模型斜率拉到约 −1，与“模型段可由 B 口径解释”一致 |
| ≥ −0.6 | 抗弯刚度口径不足以解释模型段 |
| 介于两者之间 | 不确定 |

附加规则（同样预先登记）：

1. K×1/44 的三个目标点里，只要有一个是剪切分支（|S|/W > 1e-4，沿用 R2 定义），最终判读记为“不确定（分支混合）”，b_wale 只作描述。
2. 其他 K 档如果含剪切分支点，该档斜率标注“混合分支，仅描述”，不影响主判据。
3. 主判据的前提是“充分放松态约 −1”。这个前提要由 D0 检验，报告里必须写明：本判读只说明模型能否到达 −1，不说明真实面料的斜率是多少。
4. 单调性、局部 db/dlnK、与外推值 −1.1 的差，都只报告，不设通过或失败。

## 4. 研究设计

### 4.1 共同设置

- 工况来源与 R2 相同：`docs/archive/t1-slope-closeout-2026-11-23/step3-hossain-{2.77,2.84,2.9}-input.json`。数值设置**原样沿用**：N64、q=12、`maxIterations` 24000、`innerIterations` 800、`memorySize` 180。
- 参数覆盖方式与 R2 QC 相同：先用 input.json 的参数调用 `createFabricFormParams()`，再覆盖 `K`（或等价性检查里的 `B`）。被覆盖字段的 `provenance` 写 `confidence: "DIAGNOSTIC_OVERRIDE"`、`source: "R3-a task §4"`、`principle`（例如 “K scaled by 1/16; B unchanged; diagnostic only”）、`applicableState: "R3-a stiffness-ratio diagnosis; not a material value"`。
- 全部是**自由解**（不锁 W/H），每点记录 W、H、S、shearBranch。
- 沿用 R2 脚本现有的逐点 manifest 写法（含输入 SHA-256）；**不额外**做文件哈希核对、结果双跑或性能测量。

### 4.2 延续链（预先规定）

每个 l 沿一条链逐级往下：

`K×0.5（R2-3 已收敛结果，复用不重算）→ K×1/4 → K×1/8 → K×1/16 → K×1/44`

- 每级的初值取同一 l 上一级**已收敛目标点**的终态 cell。K×1/4 的初值取 R2-3 归档里对应 l 的 `qc-<l>-K0.5` 结果文件。
- 每个目标先直接求解。若未收敛（NOT_CONVERGED 或 INFEASIBLE），允许且只允许一次重试：先在上一级和目标的几何中点 K = √(K_上一级 · K_目标) 求解，再以中点终态为初值重解目标。中点和重试都要报告。重试仍失败触发停止条件 #2。
- 求解次数：目标点 12 个；最坏情况每个目标再加 2 次（中点 + 重试），共 36 次；加上等价性检查的 1 次，**上限 37 次**。这就是唯一的上限，脚本按此设置，不另设更小的上限。

### 4.3 等价性检查（R3a-1，1+1 次求解）

验证“B×c ≡ K/c”在求解器层面成立，否则 R3-a 的结果不能解读为 B 口径。

- l = 2.84，初值同为 R2-3 的 `qc-2.84-K0.5` 终态：
  - (i) K×1/4，B 不变（即延续链的第一个点，R3a-2 直接复用，不重算）；
  - (ii) K×1（不变）、B×4。它的 K·E_f/B 与 (i) 相同，都是基准的 1/4；K 保持原值，避免和 (i) 同时改 K 造成歧义。
- 比较 (i) 和 (ii) 的 W、H、S、横密、纵密，以及能量（(ii) 的各项能量应约为 (i) 的 4 倍）。
- 通过标准：W、H 的相对差 ≤ 1e-5，|ΔS|/W ≤ 1e-5，各项能量之比与 4 的相对差 ≤ 1e-5。不通过触发停止条件 #3。
- 两次都要报告迭代数；迭代数不同不算失败。

### 4.4 每点记录

W、H、S、shearBranch、横密、纵密、kw、kc、各项能量（含 barrier 和 barrierFraction）、minDistanceOverDe、各接触组的激活段对数与 minDistanceOverDe、状态、迭代数、耗时、初值来源文件。

另加一列“势垒支撑区”：minDistanceOverDe < r_c/d_e + 0.1·(1 − r_c/d_e)（当前参数下为 0.55）或 barrier 能 > 0 时记为 true。**只记录，不停止。**

### 4.5 分析

- 每个 K 档（0.5、1/4、1/8、1/16、1/44，并列出 R2 的 1 和 2 作参照）：b_wale、b_course 及残差；l=2.84 处横密、纵密相对 Hossain 干放松值的偏差（口径同 R2：100×(T1/实测 − 1)；标注“参照为干放松态”）。
- 相邻档的局部 db_wale/dlnK，以及 K×1/44 实测 b_wale 与外推值 −1.1 的差。
- 按第 2 节给出主判据判读。
