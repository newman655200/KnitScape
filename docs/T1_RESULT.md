# T1 结果（2026-11-23）

**结论：本轮四工况 N64→N128 双方向密度变化均 ≤0.5%；Hossain 三点已完成未调参对照。** 所有终态经最终代码复核，N64/N128 及实测对照的 Q24 复核均满足原平衡门槛。

根因与修改：4.0 mm/N64 原样复现 6000 步后残差比 0.0072609。内层达到步数上限即更新 AL、清空 L-BFGS 记忆，导致罚系数升高和停滞；现保留未完成子问题的目标、乘子与曲率历史。N128 又实证舍入窗口内的无穷范数条件会拒绝整体梯度下降的步，改用梯度平方二范数。仅修改 `constrainedOptimizer.js`，在既有快检加两条回归。2.6 mm 线性细分折角诱发负初始乘子及近势垒失稳，正式链复用已有受保护 Hermite 平滑延拓。

统一设置：复用既有收敛 N32；N64/N128 的 `memorySize=180/384`，`maxIterations=24000`、`innerIterations=800`、q=12，终态复核 q=24。均为现有入口参数；物理公式、材料、容差及 B 类区间不变。仅增加预算的 60 条历史对照仍失败，180 条历史在原 6000 步预算内收敛。
