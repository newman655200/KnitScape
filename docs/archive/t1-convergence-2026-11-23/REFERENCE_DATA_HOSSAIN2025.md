## 换算与对照口径

- 横密 = 原始纵行计数 / 2.54；纵密 = 原始横列计数 / 2.54。
- kw = 横密 × l(cm)；kc = 纵密 × l(cm)，二者无量纲。
- 克重反算：GSM (g/m²) = 横密(纵行/cm) × 纵密(横列/cm) × l(mm) × tex / 100。反算值相对报告值偏差为 **+0.47% / +0.49% / +0.53%，约 0.5%**（依次对应 l=2.77/2.84/2.90 mm）。
- `hossain-comparison.json` 中密度、kw、kc 使用原始计数换算后的未舍入值；GSM 比较使用论文报告值。
- 偏差 (%) = 100 × (T1 预测值 / 实测参考值 − 1)。只报告偏差，不调参。
- 实测是干放松状态，T1 是无摩擦平衡；给纱设定长度的放松后复测情况未知。（见文末更正）
- 用户补充：同纱、同 l，仅改变沉降片时机，kc/kw 在 1.36–1.59 之间，可视为干放松状态下的工艺离散范围。

## 计数分辨率与趋势显著性

以下为 2026-11-23 用户提供的统计补充与解释；顺序均为 l=2.77/2.84/2.90 mm。T1 趋势对应本目录 `hossain-comparison.json` 的 N128 归档，不与后续 N64 诊断混称。计数分辨率与均值标准误是不同量。

- 单次读数 ±1 线圈：纵行 3.11/3.25/3.41%，横列 2.09/2.18/2.28%。
- 10 次均值的标准误：纵行 0.41/0.43/0.52%，横列 0.28/0.22/0.30%。
- l 增加 4.69%。实测横密 −9.0%（kw −4.7%），纵密 −8.4%（kc −4.1%）；T1 横密 −1.8%（kw +2.8%），纵密 −7.3%（kc −2.9%）。
- 幂次拟合：实测横密 ∝ l^-2.05，纵密 ∝ l^-1.90；T1 横密 ∝ l^-0.39，纵密 ∝ l^-1.64。
- 横密偏差斜率为 8.4 个百分点（约 11σ），即使按两端单次读数 ±1 线圈相加（7.2 个百分点）也不能解释。纵密偏差 +10.13/+10.03/+11.46%，不单调，约 3σ，暂不当作可靠信号。
- 推测：如果放松状态的影响对不同 l 大致成同一比例，它只能解释偏差水平，不能解释斜率。该前提未经验证。
- 实测的 l^-2 也偏离 l^-1；l 是给纱设定值，放松后没有复测，这是一个可能原因。（见文末更正）

## 原文核对更正（2026-11-26，据架构师 2026-11-25 在线阅读原文正文；Table 1 与 S1 File 未读到）

- 放松状态：原文只做了干放松（22 °C、67% RH、48 h），没有湿放松或充分放松数据。
- 线圈长度：原文用 HATRA 横列长度仪测横列长度并换算线圈长度（BS 5441:1988），但正文把 2.77/2.84/2.90 mm 作为给纱设定值呈现，没有单列实测值；实测值可能在 S1 File。原记录“放松后是否复测未知”更正为“做过 HATRA 测量，数值待从 S1 File 核对”。
- 克重：原文面密度由公式计算（引自 Booth 教材 Eq. iii）；另有“实际测量”，但称重方法和样本数未说明。因此“反算 GSM 与报告值相差约 0.5%”是同一公式算两遍，不能佐证实际纱长等于设定值；T1 的 GSM 偏差也不是独立观测。
- 线密度：摘要为 19.68 tex，本文件记录为 19.78 tex（用户提供），待核对。约 0.5% 的差别不影响斜率。
