# 色纱遮罩批量绘制性能优化设计

## 目标

减少右侧预览在启用色纱序列时的 canvas `stroke` 次数，缓解扫描纹理、双纱线和色纱遮罩叠加后的卡顿。

## 当前问题

当前每一段纱线路径都会单独绘制一次色纱遮罩。Width / Height 增大、第二支纱线开启、扫描纹理开启后，路径段数量和绘制层数都会增加，拖动或修改色纱序列时会明显放大卡顿。

## 方案

1. `drawYarnTexturePath` 保留纱线底色、扫描纹理、毛羽和高光绘制能力。
2. 色纱遮罩不再在每段路径内部直接绘制，而是在 `yarnSimulation` 中按图层、纱线和遮罩颜色收集路径。
3. 同一批路径合并成一个 `Path2D` 后，只调用一次遮罩绘制。
4. 默认全 0 色纱序列仍然视为无遮罩，不产生额外遮罩绘制。

## 验证

`npm run validate:two-ply-yarn` 需要验证：

1. 第一支和第二支纱线底色仍然存在。
2. 非默认色纱序列仍然产生遮罩颜色。
3. 遮罩颜色的 `stroke` 次数被压缩到图层级批量绘制数量，而不是每段纱线都绘制一次。
