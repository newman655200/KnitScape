# 色纱序列遮罩叠加设计

## 目标

左侧“第一支纱线”和“第二支纱线”的颜色始终作为右侧预览中的纱线本体底色。色纱序列只表示每一行上方额外叠加的颜色遮罩，不能替换 `yarnPlies[index].color`。

## 方案

1. `yarnSimulation` 保留每根纱线的 `color` 字段，只在色纱序列不是默认空序列时，为当前行生成 `sequenceMaskColor`。
2. `yarnTextureBrush` 先绘制纱线底色或扫描纹理，再使用 `sequenceMaskColor` 以半透明方式叠加同一路径。
3. 默认全 0 的色纱序列视为无遮罩，避免新建文件或刚打开项目时整块布被默认色纱覆盖。

## 验证

`npm run validate:two-ply-yarn` 需要同时验证三件事：

1. 第一支纱线底色仍然被绘制。
2. 第二支纱线底色仍然被绘制。
3. 非默认色纱序列会额外绘制遮罩颜色。
