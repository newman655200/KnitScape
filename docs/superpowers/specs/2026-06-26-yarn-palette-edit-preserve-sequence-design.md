# 色纱改色不回刷已画序列设计

## 目标

左侧“色纱”颜色用于后续绘制，不应在调色时自动改变中间已经画好的色纱序列。第一种颜色和第二种颜色遵循同一规则：改色后，只有用户再点击或拖动中间色纱序列中的某一行，该行才变成新颜色。

## 当前问题

色纱序列内部保存的是调色盘编号。默认序列大多是编号 `0`，所以修改第一个颜色时，所有编号 `0` 的格子会一起变色；第二个颜色通常还没有大面积使用，因此看起来行为不同。

## 方案

新增 `updateYarnPaletteColor()`：

1. 如果被修改的颜色编号没有被色纱序列使用，只更新该颜色。
2. 如果该颜色编号已经被序列使用，先把旧颜色保留下来，并把已有序列格子 remap 到旧颜色编号。
3. 原来的颜色编号更新为新颜色，并保持为当前 `activeYarn`，供后续点击或拖动中间序列时使用。

这样可以保留已画好的视觉结果，同时让新颜色只影响之后用户主动选择的行。

## 验证

`npm run validate:yarn-sequence-editor` 覆盖：

1. 修改已使用的第一个颜色时，已有 `0` 号格子 remap 到保留旧色。
2. 修改未使用颜色时，不改变色纱序列。
3. 左侧 UI 使用 `updateYarnPaletteColor()`，不再直接把原 `yarnSequence` 随新调色盘一起 dispatch。
