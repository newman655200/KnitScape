# 单次均匀纱长模拟设计

## 目标

右侧预览区的“模拟”改为单次命令。每次点击只根据当时的组织图、纱长和纱线参数计算一次线圈形变，随后保持该模拟结果，不启动持续动画，也不因后续状态变化自动重新求解。

同一组织、同一纱长、同一基础几何条件下的重复线圈必须具有一致的形状。安全限制可以压低整组线圈允许的最大形变量，但不能让同组内不同线圈获得不同的正常形变。

## 交互行为

1. 默认打开项目时不执行纱长模拟，右侧显示基础线圈路径。
2. 点击“模拟”时生成一次新的模拟请求，并计算、显示本次静态结果。
3. 模拟完成后不保留“持续运行”状态，不启动 D3 force tick，也不在后台循环重算。
4. 修改组织图、纱长、直径、颜色、色纱序列或扫描纹理时，不自动执行新的纱长求解。
5. 颜色、纹理、缩放和平移可以继续重绘显示；只要没有再次点击“模拟”，就不产生新的纱长形变解。
6. 修改会影响线圈几何的参数后，当前模拟快照视为旧结果；用户再次点击“模拟”后才使用最新参数更新形状。

## 状态与数据流

用一次性请求序号替代持续开启的 `yarnLengthSimulationEnabled` 模式语义：

- “模拟”按钮递增请求序号。
- `runSimulation` 只在请求序号变化时开启一次纱长求解。
- 普通状态同步可以重绘预览，但不得把纱长求解标记继续传递给后续重建。
- 已计算的线圈几何以快照形式保存或复用；实现应优先缓存几何路径，不冻结 canvas 位图，确保缩放后仍清晰。
- 如果现有渲染生命周期无法安全复用完整路径快照，则允许在保持旧模拟输入快照的前提下重建相同几何，但必须保证输入快照固定、求解结果确定，并通过调用次数测试证明不会因一次普通状态更新重复执行高成本求解。

## 均匀性约束

1. 不使用随机数、运行时顺序或局部自动挑边决定线圈形状。
2. 不按每个 link 的局部 flexibility 分配纱长增量。
3. 重复线圈先按组织类型、基础路径结构、行内相位和纱线参数生成稳定签名。
4. 同一稳定签名共享相同的归一化形变响应、法向方向和弧高比例。
5. 相邻距离只作为整组最大安全弧高的上限；组内采用该组最严格的安全上限，避免单个线圈被单独压缩后出现忽大忽小。
6. 端点、跨行连接、路径拓扑和前后层级保持不变，不能因均匀化产生断线、尖角或层级翻转。
7. 两根纱线分别使用各自的纱长和直径参数，但同一路径上的两根纱线必须保持附着关系。

## 验收标准

### 单次运行

- 初始加载不执行纱长求解。
- 点击一次“模拟”只产生一次新的纱长求解请求。
- 随后修改颜色、直径、纱长、组织图、色纱序列、纹理、缩放或平移时，不自动产生第二次纱长求解请求。
- 再次点击“模拟”时才产生下一次求解请求，并使用最新参数。
- “松弛”功能在单次纱长模拟结果上不得启动动态 force simulation。

### 线圈均匀性

- 使用 60×80 全上针样本，分别测试纱长 1.03 和 1.05。
- 对可比较的重复线圈按稳定签名分组，组内归一化长度响应 spread 不得大于 0.003。
- 组内法向方向和形变控制参数必须一致。
- 相同输入连续模拟两次，输出路径数据必须一致。
- 默认纱长 1.00 不改变基础路径；1.03 和 1.05 的总路径长度应依次增加。
- 原有 knit、purl、slip、tuck、双纱独立参数、跨行连接和构建测试继续通过。

## 性能边界

- 普通编辑不运行高成本纱长统计和目标长度求解。
- 单次模拟完成后不保留动画计时器或 force simulation。
- 缩放和平移只改变预览变换，不重新计算线圈几何。
- 不引入新的持续 `requestAnimationFrame` 循环。
