# KnitScape 当前界面源码说明模式设计

## 目标

在当前 KnitScape 项目中增加一个只用于学习和修改代码的“源码说明模式”。该模式直接使用项目当前真实界面，不复制目标图，也不维护另一套静态界面。

访问普通地址时，项目功能保持不变；访问带有 `?codeGuide=1` 的地址时，页面进入源码说明模式。此时点击现有控件不会执行编织、编辑、导出、缩放或弹窗等原业务功能，而是在网页内显示该控件对应的源码文件、当前行号、函数或标识符，以及应该如何修改。

## 用户体验

- 源码说明模式顶部显示明显但不遮挡界面的“源码说明模式”标识。
- 当前项目的任务栏、纱线区、针法区、编辑画布、工具栏、模拟预览和弹窗入口保持原有外观。
- 每个可见控件和关键画布区域获得稳定的 `data-code-guide-key` 标识。
- 点击标识过的元素后，右侧弹出说明抽屉。
- 抽屉显示：控件名称、实现状态、绝对文件路径、行号、函数或标识符、功能说明、修改建议。
- 抽屉提供“复制位置”和 `vscode://file/...:line` 跳转链接。
- 抽屉自身的关闭、复制和 VS Code 跳转不受业务事件拦截。
- 关闭源码说明模式后，页面恢复当前项目原有行为，不改变默认入口。

## 架构

### 模式判断

新增 `src/codeGuide/mode.js`，集中判断 URL 查询参数 `codeGuide=1`。普通模式不加载事件拦截逻辑，也不显示源码说明界面。

### 映射数据

新增 `src/codeGuide/codeGuideMap.js`，以稳定 key 保存每个界面元素的元数据：

- `title`
- `file`
- `line`
- `symbol`
- `status`
- `description`
- `changeHint`

映射内容以当前源码为准，不使用目标图中的虚构控件。未实现但用户可能需要新增的能力，只有在当前界面存在明确入口时才标记为“当前未实现”。

### 当前界面标记

在现有 Lit 模板中添加 `data-code-guide-key`，覆盖：

- `src/views/taskbar.js`
- `src/views/leftBar.js`
- `src/views/repeatTools.js`
- `src/views/chartTools.js`
- `src/components/runSimulation.js`
- `src/views/view.js` 中的编辑画布与纱线序列区域

只添加说明标识，不复制控件，不改变普通模式的事件处理。

### 事件拦截

新增 `src/codeGuide/codeGuideEvents.js`。仅在源码说明模式下，于捕获阶段处理 `pointerdown`、`click`、`input`、`change`、`wheel`、`contextmenu` 和键盘激活事件。

事件目标通过最近的 `[data-code-guide-key]` 查找映射；找到后阻止默认行为和后续业务监听器，并更新当前说明项。带有 `[data-code-guide-ui]` 的抽屉区域不拦截。

### 说明抽屉

新增 `src/codeGuide/codeGuideOverlay.js`，使用项目现有的 Lit 渲染循环生成顶部标识和右侧抽屉。当前选中项保存在源码说明模块内部，避免写入业务 `GLOBAL_STATE`。

样式放在 `styles.css` 的独立 code-guide 区段，并使用现有颜色、边框和字体变量，使其看起来属于当前项目。

## 数据流

1. `src/index.js` 初始化页面。
2. 若 URL 为 `?codeGuide=1`，注册源码说明捕获事件；普通业务输入监听器不注册。
3. `view()` 在说明模式下渲染 code-guide 标识和抽屉。
4. 用户点击带 key 的当前界面元素。
5. 捕获事件阻止原业务行为，并把 key 交给说明模块。
6. 下一次 Lit 渲染显示对应源码位置和修改说明。

## 行号维护

行号在功能完成后按最终源码重新扫描并写入映射。新增 `scripts/validate-code-guide.mjs` 检查：

- 每个页面 key 都有映射。
- 每个映射文件存在。
- 每个行号在对应文件范围内。
- 每个 VS Code 链接可以由文件和行号生成。
- 普通模式没有源码说明 DOM 和事件拦截。

以后调整相关源码后运行校验脚本；若行号发生漂移，应同步更新映射。

## 错误与兼容处理

- 浏览器禁止剪贴板时，先尝试选择复制，再尝试原生剪贴板并设置超时；失败时显示完整路径供手动复制，不阻塞页面。
- 映射 key 缺失时不执行原业务功能，并显示“尚未建立源码说明”，便于补充映射。
- VS Code 未注册协议时，文件路径仍完整显示并可复制。
- 源码说明模式不依赖外部网络，Vite 开发环境和本地构建均可显示。

## 测试与验收

- 自动校验源码文件、行号、key 覆盖和普通模式隔离。
- 构建项目并运行现有单面布、国际化和内网构建校验。
- 浏览器验证普通地址仍执行原功能。
- 浏览器验证 `?codeGuide=1` 下点击任务栏、纱线控件、针法、画布工具和预览控件会打开正确说明，且不执行原功能。
- 验证抽屉关闭、复制、VS Code 链接和窄屏显示。

## 非目标

- 不再生成目标图静态复刻页面。
- 不修改针织模拟算法、纱线算法或导出格式。
- 不上传、不提交业务改动到远程 GitHub。
- 不自动重写用户现有的其他未提交修改。
