# 织法图编辑栏精简设计

## 目标

将中间织法图上方的重复单元编辑栏精简为：宽度输入、`×`、高度输入、画笔、退出。默认界面表现为“`4 × 8 + 画笔 + 退出`”。

## 保留功能

- 宽度与高度输入继续调用 `resizeRepeatBitmap()`，改变当前重复单元尺寸。
- 画笔继续作为唯一手工织法编辑工具，使用当前选中的 knit / purl / slip / tuck 组织绘制。
- 退出继续把 `editingRepeat` 设为 `-1`，保留当前重复单元并结束编辑状态。
- 画笔快捷键 `B`、鼠标绘制和触控绘制继续有效。

## 删除功能

- 删除当前重复单元按钮及其数组删除逻辑。
- 填充、画线、矩形按钮。
- `repeatEditingTools` 中的 flood、line、rect 实现，只保留 brush。
- flood、line、rect 的工具常量与键盘快捷键。
- 仅供这些按钮使用的翻译、代码导览条目和 SVG 图标。

底层 `Bimp` 的 `flood()`、`line()`、`rect()` 方法继续保留，因为它们是通用位图能力，其他画布或未来导入处理仍可能使用；本次只删除重复单元编辑入口及其专用调用链。

## 状态与兼容性

旧 JSON 若没有 `activeTool` 不受影响。若运行时状态带有已删除的工具名，进入重复单元编辑时应回到 brush，避免出现点击画布没有反应。默认 `activeTool` 仍为 brush。

## 验证

- 编辑栏只出现两个尺寸输入、一个画笔按钮和一个退出按钮。
- 不再出现删除、填充、画线、矩形按钮或对应翻译文本。
- 画笔仍能修改重复单元并更新右侧预览。
- 退出仍能关闭编辑栏且不删除重复单元。
- 尺寸输入仍能把默认 `4 × 8` 重复单元调整为其他尺寸。
- 全部现有验证和生产构建通过。
