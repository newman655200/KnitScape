# 按行总路径长度约束的线圈形状模型

## 目标

用第一支纱线的纱长参数控制右侧普通成圈线圈的蓬松或紧致程度。模型先计算每一行当前中心线路径总长度，再根据目标纱长反求该行统一的线圈形状系数，使形变后的行总路径长度接近目标值。

第一版用于验证数学模型和视觉方向，不声称是完整的纱线材料物理仿真。

## 第一版范围

- 只验证普通成圈结构，即当前内部 `knit` / `purl` 对应的普通线圈路径。
- 只由第一支纱线 `yarnPlies[0].lengthScaleY` 决定线圈几何。
- 第二支、第三支以及未来更多纱线直接复制第一支纱线已经求出的中心路径，只改变颜色、直径、纹理或显示状态，不重复求解几何。
- 上端点和下端点在第一版中保持当前默认位置，不增加设备参数控件。
- 第一支纱线纱长滑块变化后自动、短延迟地重新计算预览，不恢复单独的“模拟”按钮。
- 当前 `0.90 - 1.10` 纱长输入范围继续作为第一层安全限制。
- 包含 slip / tuck 或无法识别拓扑的行保持原始几何，不参与第一版长度形变；模型不得导致页面崩溃或产生非有限坐标。

## 核心数学模型

所有长度计算使用归一化针距坐标，不直接使用随窗口变化的显示像素。渲染时再把归一化坐标映射到 Canvas。

对第 `r` 行，先计算基准总长度：

```text
L0(r) = 该行所有可绘制普通线圈中心曲线长度之和 + 归属于该行的转接段长度
```

第一支纱线的输入比例为 `s = yarnPlies[0].lengthScaleY`，目标长度为：

```text
Ltarget(r) = L0(r) * s
```

形状不能直接乘以 `s`，因为曲线弧长与宽度或振幅不是线性关系。每个普通线圈使用同一个参数化形状族：

```text
C(u; k) = B(u) + A(k) * w(u) * N(u),  0 <= u <= 1
```

- `B(u)` 是由当前固定锚点确定的基础路径。
- `N(u)` 是稳定、确定性的外法线方向。
- `w(u) = sin²(pi * u)`，在连接端点处位移为零并保持平滑过渡。
- `k` 是该行所有相关普通线圈共享的形状系数。
- `A(k)` 单调控制线圈外鼓幅度：较大表示更蓬松，较小表示更紧致。

对每一行用二分法求解唯一共享系数 `k`：

```text
F(k) = Lrow(k) - Ltarget(r)
```

求解停止条件同时考虑最大迭代次数和相对长度误差。第一版目标为普通支持行的相对误差不超过 `0.1%`。

如果目标长度小于固定端点之间允许的最短路径，或大于第一版安全搜索范围能够形成的最长路径，使用最近的有效边界形状并记录受限状态，不允许产生 NaN、无限坐标或反向折叠。

## 路径和连续性

长度测量以最终用于绘制的中心曲线为准，而不是控制点之间的折线距离。曲线长度通过确定性的数值采样或贝塞尔弧长近似计算；相同输入必须得到相同结果。

普通线圈的连接端点保持不动，只修改端点之间的内部曲线。形变包络在端点处为零，从而保持相邻线圈和跨行转接段连续。行末转接段必须明确归属且只计算一次，防止行总长度重复累计或遗漏。

同一行所有支持的普通线圈共享 `k`，避免重复组织出现随机松紧。边界线圈可以使用不同的基础几何，但不得使用独立随机系数。

## 渲染与状态流

第一支纱线是唯一的几何主纱：

```text
chart
-> ProcessModel / YarnModel 拓扑
-> 归一化基础中心路径
-> 按行测量 L0
-> 读取 yarnPlies[0].lengthScaleY
-> 按行求解共享 k
-> 生成最终中心路径
-> 所有纱线复用路径
-> 分别绘制颜色 / 直径 / 纹理
```

第二支及后续纱线不显示可编辑纱长滑块，改为显示“线圈形状跟随第一支纱线”的只读提示。导入旧 JSON 时仍保留这些纱线已有的 `lengthScaleY` 字段以维持文件兼容，但它们不触发几何求解，也不改变形状。代码导览同时明确只有第一支纱线纱长控制几何。

第一支纱线滑块变化使用短延迟合并连续输入，停止拖动后提交最终高质量计算。中间组织编辑、颜色、直径和纹理变化继续沿用现有刷新链路。

## 删除旧松弛功能

删除右侧“松弛”按钮、`relax` 调用链、`YarnForce` 自定义力和 `d3.forceSimulation()` 相关运行代码。旧松弛只按节点距离重新排布画面，不包含纱线弹性、摩擦、张力、机器几何或回缩参数，不能代表真实松弛程度，并会破坏已求出的行总路径长度。

D3 依赖继续保留，因为当前路径平滑仍使用 `d3.line()` 和 `curveCatmullRomOpen`。停止和纹理异步重绘能力只保留实际仍需要的部分，不为已删除的力模拟保留空接口。

## 验证

测试必须覆盖：

- `lengthScaleY = 1.00` 时，普通成圈基准路径保持不变。
- `1.10` 的行总路径长度大于 `1.00`，视觉更外鼓。
- `0.90` 的行总路径长度小于 `1.00`，视觉更内收。
- 支持行的最终总长度相对目标误差不超过 `0.1%`，无法达到目标时明确标记边界受限。
- 同一行重复普通线圈使用同一形状系数，重复形状保持一致。
- 固定连接端点在形变前后坐标不变，曲线连续。
- 第二支及更多纱线不启动额外求解，使用与第一支完全相同的路径数据。
- 颜色、直径、扫描纹理和色纱序列继续正常绘制。
- slip / tuck 或不支持行回退到原始路径且无异常。
- 右侧不存在“模拟”和“松弛”按钮，也不存在旧快照和旧力模拟执行路径。
- 全部保留验证和 Vite 生产构建通过。

## 后续方向

第一版验证通过后，再单独设计由大圆机设备参数控制上端点位置的模型。届时设备参数决定锚点几何，纱长参数仍决定目标路径长度，两者共同求解线圈形状。材料弹性、摩擦、张力、碰撞和不同针法拓扑不进入本次实现。
