# 中央针法编辑栏与统一深灰界面设计

## 目标

把针法选择和画布尺寸从分散位置集中到中间织法图正上方，让针法编辑路径更直接；左、中、右工作区统一为接近右侧预览的深灰背景，按钮和输入框保持白色。

## 已确认布局

- 顶部任务栏保留品牌、语言和文件操作，使用窄版石墨色。
- 左侧只保留双纱、纹理和色纱参数。
- 中间第一行紧凑显示针法、四个针法按钮以及“画布长 / 画布高”。
- repeat 编辑行位于其下，只保留 `4 × 8`、画笔和退出。
- 画布和缩放工具继续使用原有行为。
- 左侧、中间编辑区和右侧预览统一使用 `#4A5055`，控制条使用略浅的炭灰色。
- repeat 画笔默认白色；第一次点击启用编辑并使用深色选中态，第二次点击关闭编辑并恢复白色。鼠标和触控编辑入口都不得在关闭状态下自动回退到画笔。

## 图标约束

针法按钮必须直接使用现有 `knit.svg`、`purl.svg`、`slip.svg`、`tuck.svg`。不修改 SVG 文件内容，不用生成图、字符或新绘制图形代替。自动验证固定四个文件的 SHA-256，以阻止意外改动。

## 配色

工作区、面板与编辑栏均为 `#4A5055`，次级控制面为 `#565D62`，输入框和默认按钮为 `#FAFAF8` / `#FFFFFF`，深色选中态为 `#34383C`。针法选中仍可保留 `#A96882` 与 `#E4CFD8` 作为局部识别色。

## 验收

四个针法按钮能切换或应用针法，Width / Height 仍调整整张画布，repeat 行继续工作；1280×720 和 1080×720 无横向溢出；控制台无错误；生产构建和全部验证通过。
