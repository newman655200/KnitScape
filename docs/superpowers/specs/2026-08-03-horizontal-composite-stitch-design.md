# 左右复合线圈与防穿模 3D 验证设计

## 1. 目标

在组织图中选择一个针格后，允许它与右侧相邻且针法相同的针格组成一个“左右复合线圈”。两个原始针法图标继续存在并显示相同分组颜色；右侧预览把两个普通线圈显示为一个占两格宽度的复合线圈，并提供可旋转的局部 3D 验证视图检查穿模。

该能力是 KnitScape 内部的结构设计操作，不是大圆机指令，也不导出为机器可执行工艺。

## 2. 首版范围

### 包含

- 水平方向从选中格向右合并。
- 只允许 `knit + knit`（成圈）和 `purl + purl`（反面圈）。
- 两个组织图图标保留，并覆盖相同的分组颜色和连接标识。
- 合并关系可取消、可撤销、可随项目 JSON 保存和恢复。
- 合并后右侧自动切换到局部“3D 验证”视图。
- 3D 视图显示真实管状纱线、深度关系、旋转观察和碰撞状态。
- 原有二维/2.5D 面料预览保留，可由用户切换回来。

### 不包含

- 集圈或浮线的左右合并。它们不是两个普通线圈，需另建复合拓扑模板。
- 跨组织循环边界合并。
- 与针织设备或大圆机文件格式连接。
- 全幅面料的纱线级动力学、摩擦或材料参数反演。
- 把合并结果计入现有机器针距或百圈纱长计算。

## 3. 交互规则

工具栏增加“左右合并”按钮。

1. 用户在组织图选择一个格子。
2. 系统将该格与其右侧格作为候选。
3. 候选有效时，按钮可用；点击后建立一个复合组。
4. 选择已合并组的任意格时，按钮文案变为“取消合并”。
5. 合并成功后，右侧自动进入该组的 3D 验证视图。

以下情况按钮禁用，并通过按钮提示说明原因：

- 没有选中格。
- 选中格位于最后一列。
- 右侧格与选中格针法不同。
- 针法不是成圈或反面圈。
- 任一格已属于另一个复合组。
- 两格跨越重复单元的水平循环边界。

分组颜色只表示结构关系，不覆盖纱线配色语义。界面用半透明底色、同色针法符号和跨两格的连接框表达分组。

## 4. 状态与持久化

`GLOBAL_STATE` 增加：

```js
pairGroups: [],
activePairGroupId: null,
simulationMode: "fabric",
```

每个复合组结构为：

```js
{
  id: "pair-<stable-id>",
  left: { x: 4, y: 3 },
  right: { x: 5, y: 3 },
  stitchType: "knit",
  mode: "visual-merge",
  color: "#4f7cff"
}
```

坐标采用组织图交互层的左上原点坐标，`left.x + 1 === right.x` 且两者 `y` 相等。需要读位图针法时，再转换为 Bimp 使用的纵向坐标。

`pairGroups` 进入快照字段，因此合并和取消可以撤销。JSON 导出包含该字段；旧项目没有该字段时按空数组加载。导入、改变画布尺寸或重新生成组织图时执行标准化，删除越界、重叠、异类或针法已改变的失效分组。

## 5. 组织图显示

新增独立的复合组覆盖层，不修改底层 `chart` 和 `repeat.bitmap`：

- 覆盖层与组织图画布使用相同的缩放和平移。
- 每组绘制一个跨两格的圆角框。
- 两个格子各自绘制原针法图标，但使用同一分组色。
- 覆盖层 `pointer-events: none`，不影响现有选格、画笔和拖动画布。

底层数据保持不变，因此取消合并无需重建针法。若用户后来用画笔改变组内任一格的针法，标准化逻辑立即移除该组，避免图形关系和针法数据矛盾。

## 6. 复合拓扑

复合组在组织图中仍占两个格，在 3D 渲染图中编译为一个可见线圈单元：

- 一个宽圈头。
- 左右两条外侧圈柱。
- 中间重复圈柱不生成。
- 水平方向保留进纱口和出纱口。
- 内部保留左、右两个逻辑连接区，对应原来的两个针格。

“一个可见线圈 + 两个逻辑连接区”确保上排和下排没有合并的普通线圈仍能分别连接复合线圈的左、右半区。逻辑连接区不绘制为第二个圈头。

成圈和反面圈使用相同的宽轮廓，但交织的前后顺序相反。该差异由拓扑约束和 Z 坐标表达，不能只用颜色或图层名称代替。

## 7. 局部 3D 几何

3D 验证视图只构造活动复合组周围的局部窗口：复合组本身、左右各一列、上下各一排。窗口外的连接口固定为边界锚点。

几何生成步骤：

1. 按针格间距建立普通线圈模板。
2. 用两格宽的复合模板替换活动组的两个普通线圈。
3. 根据成圈或反面圈写入交织点的前后顺序。
4. 将模板采样为三维中心线折线。
5. 执行局部长度、平滑和碰撞约束投影。
6. 将求解后的中心线转换为 Three.js `TubeGeometry` 管状纱线。

用户可以拖动旋转、滚轮缩放，并可从正面、背面和侧面检查。WebGL 深度缓冲必须开启。

## 8. 防穿模约束

每根纱线以中心线和半径 `r` 表示。对于两段不应接触的纱线，必须满足：

```text
中心线最短距离 >= r1 + r2 + clearance
```

碰撞分为：

- **预期接触**：拓扑指定的交织点。保留接触关系，并强制正确的 Z 方向前后顺序。
- **非预期碰撞**：没有拓扑关系但实体距离小于阈值。沿两段最短分离方向局部推开。

求解器规则：

- 用均匀空间哈希做粗检测，网格边长取当前最大纱线直径与安全间隙之和，避免检查所有线段组合。
- 用三维线段最短距离做窄检测。
- 同一中心线中共享端点或相邻的线段不参与自碰撞。
- 外围锚点固定；复合圈头、圈柱和直接邻居可移动。
- 每轮先投影碰撞约束，再投影长度和平滑约束。
- 最多执行 24 轮；全部非预期碰撞的穿透深度小于 `0.001` 针格单位时提前停止。
- 平滑完成后再做一次完整碰撞检查。

如果仍存在非预期穿透，3D 视图显示红色“结构冲突”和碰撞数量，不能使用遮罩隐藏问题。没有碰撞时显示绿色“未检测到穿模”。

## 9. 组件边界

- `src/actions/pairGroups.js`：候选判断、建立/取消分组、标准化和纯函数校验。
- `src/views/pairGroupOverlay.js`：组织图分组覆盖层。
- `src/simulation/mergedPairTopology.js`：把活动分组编译为普通/复合线圈逻辑端口。
- `src/simulation/yarnCollision3d.js`：三维线段距离、碰撞检测和局部约束投影。
- `src/simulation/mergedPairGeometry3d.js`：模板、采样、边界锚点和碰撞求解编排。
- `src/components/mergedPair3dView.js`：Three.js 场景、管状渲染、相机和旋转交互。
- 现有 `runSimulation.js`：负责在原预览和 3D 验证模式之间切换，不承载碰撞数学。

纯数据与几何模块不得依赖 DOM，以便使用 Node 脚本直接测试。

## 10. 错误处理

- 无效候选不修改状态，返回稳定的原因代码供中英文界面翻译。
- 导入的复合组逐项校验，不可信字段不会进入状态。
- Three.js 或 WebGL 初始化失败时保留原预览，并显示“当前设备无法打开 3D 验证”。
- 几何中出现 `NaN`、无限值或零长度路径时终止该次绘制，显示结构错误，不把无效顶点传入 WebGL。
- 切换活动组时销毁旧 `TubeGeometry` 和材质，避免显存持续增长。

## 11. 验收标准

### 数据与交互

- 同类相邻成圈可以合并；同类相邻反面圈可以合并。
- 不同针法、集圈、浮线、末列、跨循环边界和重叠分组不能合并。
- 合并后两个图标仍可辨认且颜色一致。
- 取消和撤销后恢复原始状态。
- 改变组内针法后失效组自动清除。
- JSON 保存和重新载入后分组关系一致。

### 3D 结构

- 活动组只显示一个占两格宽度的圈头和两条外侧圈柱。
- 上下排普通线圈仍分别连接左右逻辑连接区。
- 成圈与反面圈的前后交织顺序相反。
- 视图可以旋转和缩放，侧面能观察到真实 Z 间距。
- 渲染使用有半径的管状纱线和深度缓冲。

### 碰撞

- 线段最短距离算法覆盖平行、交叉、端点接近和退化线段。
- 相邻线段不会被误判为自碰撞。
- 构造一个故意穿透案例时，测试先检测到碰撞；求解后距离达到安全阈值或报告未解决冲突。
- 最终视图明确显示碰撞状态，不允许静默穿模。

### 回归

- 原组织编辑、针法画笔、二维预览、纱线纹理和项目导入导出继续工作。
- 所有现有验证脚本通过。
- `npm run build` 成功。

## 12. 理论依据

- TopoKnit 使用 Contact Neighborhood 将针法指令编译为纱线接触拓扑，支持将逻辑针格与最终纱线图形分离：<https://doi.org/10.1016/j.gmod.2021.101114>
- Kaldor、James 和 Marschner 将纱线表示为具有直径的 B 样条管，并处理弯曲、长度与纱线接触，是本设计“中心线 + 半径 + 接触约束”的依据：<https://doi.org/10.1145/1360612.1360664>
- Fukuta 等人的纬编结构建模使用锚点和样条曲线构造普通、反面、集圈和浮线等三维几何，支持首版采用参数化模板而不是完整动力学：<https://doi.org/10.4188/jte.57.37>

本设计的局部约束投影是面向交互验证的工程近似，不宣称等同于完整纱线物理仿真。
