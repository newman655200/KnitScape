# KnitScape 功能范围精简设计

日期：2026-08-23
状态：方案 A 已确认

## 目标

保留本轮已经验收的排针、尺寸、双循环编辑区、共享视角和共享色纱功能，删除由反复审查产生的死代码、重复验证和未实施方案。精简后普通页面的视觉和操作不得变化。

## 保留内容

- 默认 60×60 与可输入、可步进的横向/纵向针数。
- 三角座和排针默认 8×4；开始排针保持 8×4，应用 1/2/3/4 后排针变为 4×8。
- 黑色循环单元、灰色完整平铺、16×16 初始视角、同步滚轮缩放和中键拖拽。
- 两侧固定且共享的色纱条。
- JSON v3 与旧文件迁移，以及现有模拟和导出数据链路。

## 删除与收缩

1. 删除未实施的“大画布可视切片”方案，不在本次精简中增加性能架构。
2. 删除没有生产消费者的 `patternEdit` 状态及仅为它存在的断言。
3. 删除完全被行为验证覆盖的静态连线脚本；保留的脚本去掉重复源码正则、重复 Canvas/事件夹具和审查过程性断言。
4. 源码说明模式只保留新控件正常显示所需的最小映射，撤回本轮额外加入的 BFCache 和分隔条生命周期加固。
5. 不重构既有模拟、导出、色纱材质或其他侧栏功能，不顺手清理本轮之前的代码。

## 验证边界

精简前后使用同一组用户行为作为契约：尺寸输入字体保持黑色；两个编辑区的 8×4/4×8 转换正确；灰区只读；缩放和平移同步；色纱不与灰区交叉且两边同步；文件、模拟和导出继续读取完整排针结果。

最终必须通过生产构建和保留下来的全部验证，并重新检查工作区无临时文件。测试数量不是目标；每个保留脚本必须能对应至少一项用户可观察行为或必要的数据兼容性。

## 非目标

- 本次不实现 500×500 可视切片渲染。
- 不增加键盘画布编辑、无障碍扩展或新的源码说明能力。
- 不改变已经确认的页面布局、颜色、默认数值和交互手感。
