# 针织实验室（单面布）功能需求文档

版本：v1.0
日期：2026-06-23
用途：用于后续独立重写“针织实验室（单面布）”软件。本文只描述功能、交互、数据和验收标准，不作为原项目源码实现说明。

## 1. 项目目标

针织实验室（单面布）是一款面向针织实验、组织设计和内部样品评估的网页工具。用户可以在网页中编辑单面布针法图案，设置画布尺寸、最小针法重复单元、两根纱线的颜色/直径/扫描纹理，并在右侧查看单面布纱线模拟效果。软件应支持本地运行、完全离线安装、公司内网静态部署和多语言界面。

核心目标：

```text
单面布针法编辑
整张画布尺寸控制
最小 repeat 单元编辑
双纱参数设置
扫描纱线纹理导入与预览
右侧单面布 2D 纱线模拟
JSON 导入导出
机器/打孔卡相关格式导出
多语言界面
离线安装与内网发布
```

```text
内部演示和样品评估人员
```


双纱参数至少包含：

```text

是否启用

```

扫描纹理配置至少包含：


```text

异常 JSON 应给出清晰错误提示，不应导致页面崩溃。
```

## 8. 画布尺寸需求

顶部 Width / Height 表示整张单面布画布尺寸。

行为要求：

```text
用户输入 Width 后，中间主画布宽度同步变化。
用户输入 Height 后，中间主画布高度同步变化。
第一组 repeat 的作用区域应默认同步到整张画布尺寸。
右侧预览应基于新的整张画布重新生成。
输入值必须转为整数。
建议限制范围：最小 5，最大 500。
超出范围时自动夹到合法范围。
```

示例验收：

```text
输入 Width = 60，Height = 80。
中间主画布逻辑尺寸变为 60 x 80。
第一组 repeat 作用区变为 60 x 80。
最小 repeat 位图仍保持原尺寸，例如 4 x 8。
右侧模拟预览重新渲染。
```

## 9. 最小 repeat 单元需求

repeat 是可控制针法的最小重复单元。默认可使用 4 x 8。

repeat 工具栏必须包含：

```text
删除当前 repeat
repeat 宽度输入框
repeat 高度输入框
画笔
填充
画线
矩形
退出编辑
```

行为要求：

```text
repeat 宽高输入框只改变最小 repeat 位图尺寸。
repeat 宽高输入框不直接改变整张画布尺寸。
repeat 位图改变后，中间画布按新 repeat 周期重复显示。
用户可点击某个 repeat 进入编辑状态。
编辑状态下显示 repeat 工具栏和边界按钮。
退出后隐藏 repeat 工具栏。
```

不需要的功能：

```text
不保留平移 repeat 工具。
不保留移动 repeat 工具。
不保留画布内多余缩放按钮。
不保留左下角色纱序列拖动高度按钮。
```

## 10. repeat 作用区边界需求

repeat 作用区表示某个 repeat 在整张画布中的控制范围。

必须支持：

```text
右侧边界拖动：调整 repeat 作用区宽度。
上/下方向边界拖动：调整 repeat 作用区高度。
手动拖动边界后，第一组 repeat 的作用区变化应同步主 chart 尺寸。
Width / Height 输入框也应反映最新画布尺寸。
repeat 作用区最小不得小于 repeat 位图宽高。
```

示例验收：

```text
画布为 60 x 80，repeat 最小单元为 4 x 8。
用户拖动宽度边界增加 3 格。
repeat 作用区变为 63 x 80。
主画布变为 63 x 80。
顶部 Width 显示 63，Height 保持 80。
```

## 11. 针法符号需求

第一版必须支持四种针法符号：

```text
knit
purl
slip
tuck
```

界面要求：

```text
中间针法编辑栏显示四个针法按钮。
按钮显示文字和图片预览。
四个按钮必须直接使用 `src/assets/symbols/` 中现有的 knit / purl / slip / tuck SVG，不得替换或重画图标。
中间针法画布仍按标准线条符号绘制，不受编辑栏布局变化影响。
点击针法按钮后，若当前已有选中的 repeat cell，则立即把该 cell 替换成所选针法。
若没有选中 cell，则只切换当前活动针法。
```

## 12. repeat 编辑工具需求

画笔：

```text
按住并拖动时，将经过的 cell 改成当前针法。
拖动跨格时应连续画线，不应出现明显断格。
```

填充：

```text
对点击位置相同针法区域做连通填充。
填充目标为当前活动针法。
```

画线：

```text
从按下位置到当前拖动位置形成直线。
松开后保留最终直线结果。
```

矩形：

```text
从按下位置到当前拖动位置形成矩形区域。
矩形区域内 cell 改为当前针法。
```

删除：

```text
删除当前正在编辑的 repeat。
删除后退出当前 repeat 编辑状态。
```

撤销：

```text
顶部撤销按钮应恢复最近一次图案相关修改。
撤销范围至少包括 repeat、色纱、双纱参数等主要编辑数据。
语言切换、弹窗开关、缩放/平移不应进入撤销历史。
```

中间画布显示完整 chart。

显示层级：

```text
色纱序列区域
色纱颜色层
针法符号层
网格层
选中 cell 高亮
repeat 作用区层
repeat 边界层
```

交互要求：

```text

中键拖动或空白区域拖动可平移主画布。

适配按钮可让主画布居中并尽量完整显示。
Cols / Rows 滑块可在大画布下快速移动可视区域。
```

左侧必须支持色纱管理。

功能包括：

```text
显示当前色纱列表。
选中某个色纱。
编辑色纱颜色。
添加随机颜色。
删除已有颜色，但至少保留一种颜色。
打乱颜色顺序。
随机生成全部颜色。
```

行为要求：

```text
修改色纱颜色后，中间画布和右侧预览应刷新。
删除颜色后，色纱序列引用应自动回退或重映射，避免无效索引。
```

## 15. 双纱参数需求

左侧必须提供明显的“双纱参数”区域。

第一支纱线：

```text
颜色可编辑。
直径可调。
默认启用，不提供关闭开关。
```

第二支纱线：

```text
颜色可编辑。
直径可调。
可开启/关闭显示。
默认启用。
第二支纱线在预览中附着在第一支纱线的同一路径上。
```

直径范围建议：

```text
最小 0.06
最大 0.50
步进 0.01
```

默认值建议：

```text
第一支纱线颜色：灰色 rgba(190,190,190,1)
第一支纱线直径：0.24
第二支纱线颜色：蓝色 rgba(80,140,220,1)
第二支纱线直径：0.14
```

## 16. 扫描纱线纹理需求

每根纱线都必须支持本地图片导入作为扫描纹理。

导入要求：

```text
支持 PNG / JPEG / WebP。
导入方式为本地文件选择，不上传服务器。
适合白底或浅色背景的单根直线纱线图片。
导入后自动裁切有效内容边界。
导入后可去除白底/浅底。
导入后生成压缩后的预览纹理。
导入失败时显示清晰提示。
```

每根纱线纹理控件必须包含：

```text
导入图片
纹理预览
当前文件名或未导入状态
启用纹理
使用扫描原色
纹理尺寸：256 / 512 / 1024
去背景
纹理强度
毛羽强度
清除纹理
```

行为要求：

```text
关闭“启用纹理”不删除图片，只在右侧预览中回退为纯色线条。
关闭“使用扫描原色”后，纹理应按纱线当前颜色染色。
修改纹理尺寸或去背景阈值后，应重新处理原始图片。
修改纹理强度或毛羽强度后，右侧预览应刷新。
清除纹理后，纱线回到纯色显示。
```

## 17. 预览性能需求

必须提供全局预览性能设置：

```text
自动
质量
纯色
```

自动模式：

```text
默认模式。
用户拖动、触控拖动、滚轮缩放、预览缩放按钮操作期间，临时使用纯色快速预览。
用户停止操作后恢复纹理预览。
```

质量模式：

```text
始终按启用纹理渲染。
适合最终检查，但可能较卡。
```

纯色模式：

```text
保留已导入图片数据。
右侧预览全部使用纯色线条。
适合低配置电脑或大画布。
```

性能要求：

```text
默认新导入纹理尺寸建议为 512，低配版本可默认 256。
两根纱线同时启用纹理时，界面仍应可操作。
画布尺寸较大时应优先保证编辑交互流畅。
```

## 18. 右侧单面布预览需求

右侧预览用于显示单面布纱线模拟效果。

渲染要求：

```text
使用 2D 预览即可，不要求真实 3D 厚度。
预览分为 back / mid / front 三层。
基于完整 chart 生成纱线路径。
第一支纱线沿主路径绘制。
第二支纱线附着在同一路径上，并可用不同颜色和直径显示。
启用扫描纹理时，沿路径叠加纹理、阴影、高光和毛羽近似效果。
未启用扫描纹理时，使用纯色线条。
```

交互要求：

```text
左键拖拽：平移预览。
滚轮：缩放预览。
缩小按钮：降低预览缩放。
放大按钮：提高预览缩放。
缩放滑块：连续调节预览缩放。
适配按钮：重置平移和缩放。
翻面按钮：交换 front/back 层级，显示织物另一面。
松弛按钮：重新运行或继续放松纱线模拟。
```

明确不做：

```text
不做左键旋转。
不做右键平移。
不把 2D 面片伪装成真实 3D 模型。
```

## 19. 图库需求

功能要求：


项目必须提供 `安装环境` 文件夹。

离线环境至少包含：

```text
Windows x64 运行环境包
项目离线依赖包
一键安装环境脚本
一键运行项目脚本
一键打包发布脚本
一键验证环境脚本

```

目标：


## 24. PBR 与真实 3D 后续方向

当前第一阶段不要求真实 3D 模型，也不要求完整 PBR。

第一阶段只要求：

```text
扫描纱线图片作为 2D texture brush 使用。
右侧预览表现出近似纱线纹理、毛羽和颜色差异。
PBR 字段可在数据结构中预留，但不声称已完成完整 PBR。
```

后续增强可做：

```text
baseColor 导出
height 导出
normal 导出
roughness 导出
ambientOcclusion 导出
PBR zip 导出
真实 3D 纱线路径、穿插、穿模检查
材质 UV 展开与无缝平铺
```

PBR 验收标准：

```text
baseColor 与预览颜色一致。
normal 无明显接缝。
height 能表达针法凹凸。
roughness 不全白不全黑。
AO 能体现纱线交叉阴影。
zip 内文件命名稳定。
```

真实 3D 风险：

```text
针法穿插关系复杂，容易穿模。
路径交叉处需要明确上下层规则。
纱线直径变化会影响碰撞和间距。
扫描纹理用于 3D 时需要稳定 UV 映射。
大画布实时 3D 预览可能需要 GPU 优化。
```

## 25. 非功能需求

易用性：

```text
默认打开即可看到完整工作界面。
按钮文案清晰，不让内部用户猜测功能。
不保留无用途或容易误触的按钮。
```

性能：

```text
常规 60 x 80 画布应可流畅编辑。
纹理预览卡顿时，自动模式应优先保证拖动和缩放流畅。
大画布或高分辨率纹理下允许降低预览质量。
```

可靠性：

```text
导入错误文件不得导致白屏。
图片处理失败应显示明确提示。
撤销不得破坏工程数据。
导出文件应可重新导入或被目标工具识别。
```

可维护性：

```text
单面布功能应独立成模块。
UI 文案统一走 i18n。
核心数据结构应有版本字段或兼容策略。
```

授权：

```text
正式商用前检查所有依赖许可证。
避免 GPL 依赖进入闭源商用版本。
保留第三方许可证声明。
```
